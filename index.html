What this proves

Compliance isn't a document — it's how the system is built

Every capability below maps to a control a DoD contractor has to satisfy. This lab demonstrates them running, not described on a slide.

ACCESS CONTROL

Only authorized people run anything

Central identity gates who can log in and what automation they're allowed to execute — the same identity/RBAC model used in Linux-heavy contractor shops.

ACCOUNTABILITY

Every action traces to a named user

Automation jobs and system events are logged with user attribution and aggregated into a SIEM, so any change can be answered with "who, what, when."

DETECTION

The system watches itself

Runtime threat detection and file-integrity baselines run continuously across every node, flagging unexpected behavior instead of waiting for an audit.

GOVERNED AUTOMATION

Automation driven by a source of truth

A CMDB feeds inventory into the automation platform, so what gets configured is driven by authoritative data — not hand-maintained host lists.

Identity & automation pipeline

FreeIPA controls who can run automation via LDAP identity feeding AWX RBAC and Kubernetes namespace permissions. NetBox — the source of truth — drives what gets automated through AWX dynamic inventory. Every action is logged with user attribution in the AWX audit trail. That's enterprise automation governance: identity-gated, inventory-driven, fully auditable.

Engineering rationale

Key technical decisions

Why Rocky Linux 9?

Binary-compatible with RHEL 9 — the standard OS in DoD contractor environments and approved for AWS GovCloud (IL2/IL4). Configurations transfer directly to classified environments.

Why RKE2?

DISA STIG-compliant by default and the recommended Kubernetes distribution for DoD. Ships with CIS benchmark hardening, Pod Security admission, and containerd instead of Docker.

Why FreeIPA + AWX + NetBox?

This trio mirrors the identity/automation/CMDB pipeline used in real DoD contractor shops: FreeIPA replaces AD in Linux-heavy environments, AWX provides auditable automation, and NetBox is the source-of-truth inventory that drives automation at scale.

Transferability

Built to move to AWS GovCloud

Nothing here is a toy. Every layer is chosen so the lab lifts into an IL2/IL4 environment with region and AMI changes only.

  • Rocky Linux 9 → RHEL 9 — binary compatible, GovCloud approved
  • RKE2 — DISA STIG compliant, GovCloud supported
  • FreeIPA — approved for IL2/IL4 identity management
  • Terraform / Ansible — infrastructure-as-code requires only region and AMI updates
